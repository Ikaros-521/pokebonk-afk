# PokéBonk 后台挂机助手

给 [pokebonk.com](https://pokebonk.com/)（3D 宝可梦幸存者页游）做的挂机工具：
**Alt+Tab 切屏后游戏不再暂停、后台继续运行，并自动执行 WASD 绕圈 + 空格攻击 + Shift 技能的打怪策略**，你就可以切出去干别的事了。

> 📦 仓库地址：<https://github.com/Ikaros-521/pokebonk-afk> · 🧩 油猴一键安装：<https://greasyfork.org/zh-CN/scripts/603082> · 当前版本 **v1.2.0**（适配游戏 v0.8.83，游戏大更新后如失效请提 issue）

提供两种等价的安装方式，任选其一：

| | 方案 A：油猴脚本 | 方案 B：Chrome 扩展 |
|---|---|---|
| 文件 | `pokebonk-afk.user.js` | `extension/` 文件夹 |
| 前提 | 浏览器装 Tampermonkey / Violentmonkey | 无 |
| 安装难度 | 粘贴一次 | 加载一次 |
| 还能切出浏览器窗口？ | 只在浏览器内后台挂机 | 同左 |

两者核心代码完全相同（`extension/core.js`），功能无差别。

## 功能

- **防切屏暂停**：覆写 `document.hidden` / `visibilityState` / `hasFocus`，拦截 `blur` / `visibilitychange` / `pagehide` 事件——游戏以为你永远在线，切屏/失焦不再触发自动暂停，按键也不会被"失焦清空"。
- **后台接力**：游戏主循环是 requestAnimationFrame 驱动的，标签页被切后台后浏览器会停掉 rAF。脚本把 rAF 换成 Web Worker 驱动的 16ms 接力（前台走原生 rAF，后台自动切换），并可选播放一段约 -40dB 的近无声保活音频，避开 Chrome 对后台标签页的定时器限流。
- **自动化策略**（页面右上角面板可调）：
  - **绕圈**：八方向序列 `W→WD→D→DS→S→SA→A→AW` 依次按住，形成圆圈走位；可调顺/逆时针、每步毫秒数。
  - **空格**：点按（默认每 400ms 按一下）或长按，或关闭。
  - **Shift**：点按（默认每 2s 触发一次，类似冲刺/技能）或长按，或关闭。
  - **大招 R 有就放**：终极技（贝壳旋风）自动点按 R，每 900ms 探一次（间隔可调），未充能时按了也无副作用。
  - **交互 E 短间隔点按**：拾取 / 激活祭坛 / 捕捉等交互默认每 1500ms 探一次（间隔可调，无目标时按了无副作用）。交互弹出的选择界面自动处理：**"弹窗选第几项"可配 1–4（默认 1）**，选的序号不存在时自动兜底第 1 项，仍失败最后按 Esc。
  - **E 卡死自适应退避**：若 E 弹窗选不了任何项（人还没走出触发区，会"弹窗→Esc→又弹"卡循环），守护器检测到 Esc 兜底后自动把 E 间隔翻倍延长（3s→6s→…上限 60s，控制台有日志）；之后每 15 秒没再卡就减半，逐步恢复正常间隔。
  - **自动恢复暂停**：检测到暂停弹窗后自动点击"继续"按钮（多语言文本匹配，v0.8.83 实测通过；不依赖会随版本变化的类名，也不用 Esc——游戏里 Esc 在部分界面是"返回"）。挂机未启动时只在页面切到后台才生效，你本人前台开着暂停界面翻设置不会被抢点。
  - **结算自动再来一次**：死亡/胜利结算界面自动点击"再来一次"，挂机不断档（可关）。
  - **断线自动重试 + 自动恢复挂机**：掉线弹窗自动点"重试"直到服务器恢复；刷新/重连后若之前在挂机会自动继续挂机。
  - **自动选升级**：升级三选一弹窗自动选（默认第 1 项，与上面的"弹窗选第几项"联动，无效则点卡/Esc 兜底），避免挂机卡在升级界面。
- **控制方式**：面板按钮 / **F8** 启停挂机 / **F9** 显隐面板 / 扩展弹窗按钮（方案 B）。设置自动保存在 localStorage。

## 方案 A：油猴脚本安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome/Edge 商店均可）。
2. 安装脚本，三种方式任选：
   - **Greasy Fork（推荐，自动更新）**：打开 <https://greasyfork.org/zh-CN/scripts/603082>，点绿色"**安装此脚本**"按钮即可，之后脚本会随发布自动更新。
   - **GitHub 一键安装**：直接打开
     <https://raw.githubusercontent.com/Ikaros-521/pokebonk-afk/main/pokebonk-afk.user.js>
     Tampermonkey 会自动弹出安装页，点"**安装**"即可。
   - **手动粘贴**：点 Tampermonkey 图标 → 添加新脚本 → 清空，把 [`pokebonk-afk.user.js`](https://github.com/Ikaros-521/pokebonk-afk/blob/main/pokebonk-afk.user.js) 的全文粘贴进去 → `Ctrl+S` 保存。
3. 打开（或刷新）<https://pokebonk.com/>，右上角出现"PokéBonk 挂机助手"面板即成功。
   - 控制台会打印 `[PokéBonk AFK] 已加载`。
   - Chrome 的新版油猴即使没开"开发者模式"，脚本也会自动通过 `<script>` 注入主世界，无需额外设置。
4. **更新**：Greasy Fork 安装的会自动更新；GitHub 一键安装/手动粘贴的重新覆盖安装即可；本地设置（圈大小等）不会丢。

## 方案 B：Chrome 扩展安装（无需油猴）

1. 获取 `extension` 文件夹，两种方式任选：
   - **下载 ZIP**：打开 <https://github.com/Ikaros-521/pokebonk-afk/archive/refs/heads/main.zip> 并解压（得到 `pokebonk-afk-main/` 文件夹）。
   - **git 克隆**：`git clone https://github.com/Ikaros-521/pokebonk-afk.git`
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
3. 打开右上角"**开发者模式**"。
4. 点"**加载已解压的扩展程序**"，选择 `extension` 文件夹（ZIP 方式位于 `pokebonk-afk-main/extension`）。
5. 打开 <https://pokebonk.com/>，右上角出现面板即成功；浏览器工具栏的扩展图标点开也有启动按钮。
6. **更新**：重新下载/拉取代码后，在 `chrome://extensions` 里点该扩展的刷新按钮 ↻，再刷新游戏页即可（本地设置不丢）。

## 使用方法

1. 进入一场对局（开局跑起来之后）。
2. 按 **F8**（或点面板上的"▶ 启动挂机"）。状态变绿、显示"运行中"。
3. **Alt+Tab 切出去干别的事**——游戏会继续绕圈打怪。
4. 回来后按 F8 停止（面板也会自动松开所有按键，不会卡键）。

> 建议进对局后再开挂机；菜单界面里按键无副作用，但没必要。

### 参数建议

| 参数 | 默认 | 说明 |
|---|---|---|
| 圈大小(ms/步) | 1000 | **这就是绕圈大小**：每步走得越久圈越大。400 左右贴脸小圈，1000+ 大圈拉扯，80–3000 可调 |
| 空格间隔 | 400 | 主力输出。若空格是冷却技，调成 800–1500 |
| 空格模式 | 点按 | 长按适合持续型攻击 |
| Shift 间隔 | 2000 | 若 Shift 是冲刺/位移技，间隔太密会一直冲，可调大或关掉 |
| Shift 模式 | 点按 | 长按适合持续技 |
| R间隔 | 900 | 大招探充能的频率；"有就放"模式下按了没充能也无副作用 |
| 大招 R | 有就放 | 关掉则不自动放终极技 |
| E间隔 | 1500 | 交互键（拾取/激活/捕捉）的探测频率。若 E 弹窗选不了导致卡循环，会自动翻倍退避（上限 60s），15 秒不卡逐步恢复 |
| 交互 E | 点按 | 关掉则不自动交互 |
| 弹窗选第几项 | 1 | 选择弹窗（升级/祭坛等）首选项，可配 1–4；该项不存在自动兜底第 1 项 → Esc |
| 自动关闭暂停 | 开 | 暂停弹窗自动点"继续"。游戏内 **P 键**是暂停键 |
| 结算自动再来一次 | 开 | 死亡/胜利后自动开新对局，挂机不断档 |
| 断线自动点重试 | 开 | 掉线弹窗自动重连；重连后自动恢复挂机 |

先用默认值跑一圈，按游戏实际手感微调即可。

## 后台挂机的可靠性（重要）

浏览器对后台标签页有三层限制，脚本已绕过前两层，第三层给你两个选择：

1. **窗口别被完全盖住**（最省事）：游戏窗口留一条边可见、或放到另一台显示器、或缩小窗口——完全不受影响。
2. **保活音频**（默认开启）：脚本播放一段约 -40dB 的近无声音频（听不见），让 Chrome 认为标签页"正在播放声音"，从而豁免后台定时器限流。窗口即使被完全遮挡也能继续跑。
3. **完全保底**（如果上面还有问题）：双击本目录的 `用Chrome专用窗口启动(最大后台兼容).bat` 启动一个专用 Chrome 窗口，它带这些参数：
   `--disable-backgrounding-occluded-windows --disable-renderer-backgrounding --disable-features=IntensiveWakeUpThrottling,CalculateNativeWinOcclusion`（另有 `--no-first-run` 跳过首次设置向导）。

   **为什么不会自动装扩展？** 这个窗口用的是独立配置目录（`%LocalAppData%\Chrome-PokeBonk-AFK`），和你日常浏览器不共享扩展；而 Chrome 137 起，官方版 Chrome 出于安全考虑已忽略 `--load-extension` 命令行参数（实测 Chrome 156 确认），所以 bat 无法替你自动加载，**第一次需要手动装一次，装完永久保留**，以后直接双击 bat 即可：

   1. 双击 bat，等新 Chrome 窗口打开。
   2. 在该窗口地址栏输入 `chrome://extensions/` 回车。
   3. 打开右上角"**开发者模式**"开关。
   4. 点"**加载已解压的扩展程序**"，选择本目录下的 `extension` 文件夹。
   5. 打开 <https://pokebonk.com/>，右上角出现面板即成功。

   > 想省掉这步可以用 Edge：Edge（实测 156）仍支持 `--load-extension`，把 bat 里的浏览器路径改成 `msedge.exe` 并在参数里加一行 `--load-extension="%~dp0extension"` 就能全自动加载。

   注意：minimized（最小化）状态任何方案都无法渲染，别最小化，切出去即可。

另外：Chrome 的"内存节省程序"可能把挂了很久的标签页整个丢弃。到 `chrome://settings/performance` 把 pokebonk.com 加入"始终保持活跃"名单。

## 注意事项

- **游客登录有人机验证**：合成点击过不了"验证你是真人"，第一次进游戏请手动登录——这不影响挂机（游戏内移动按键不校验 isTrusted，已实测）。
- **升级/进化自动选第一项**：不一定是最佳选择，只是防止挂机卡死。想要手动选就关掉面板里的开关，回来手选。
- **死亡/结算界面**不会自动处理，回来手动 F8 停止再重新开局。
- **游戏声音**：因为游戏"以为"自己一直可见，它自带的"后台静音"设置不会生效。想静音就在标签页上右键→将标签页静音，或调游戏音量。
- **多开/联机**：策略只是模拟键盘，联机模式下同样生效；但挂机打联机请自担风险。
- **公平性提示**：这是非官方同人免费游戏。挂机本质是自动化按键，可能违反游戏服务条款或影响其他玩家（联机时），请酌情使用、自担风险。脚本不修改游戏数据、不加速、不注入游戏逻辑，只发送键盘事件和反暂停。

## 故障排查

| 现象 | 处理 |
|---|---|
| 右上角没有面板 | F9 切换显隐；控制台(F12)看有没有 `[PokéBonk AFK]` 日志和红色报错 |
| 面板在但启动后不动 | 确认在对局内（不是菜单）；确认游戏按键就是 WASD/空格/Shift（游戏设置里可查） |
| 切后台后卡住不动 | 开着"后台保活音"开关；或用 bat 启动器；或别把窗口完全盖住 |
| 双击 bat 闪退 / 中文乱码 | bat 必须是 **ANSI(GBK) 编码 + CRLF 换行**（2026-10-31 版已修复）。如果你自己用编辑器改过 bat，用记事本"另存为"选 ANSI 保存即可；另外 rem 注释行里不要写 `%变量%`，会导致 cmd 读行错位 |
| 后台变慢（约1步/秒） | 保活音频没生效（autoplay 被拦）：先在页面点一下/按一次 F8 再切走；或用 bat |
| 油猴脚本报"无法注入主世界" | 正常降级提示，重启浏览器再试；或改用方案 B 扩展 |
